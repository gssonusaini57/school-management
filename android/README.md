# KIS Attendance — Android App

Native Kotlin + Jetpack Compose. Talks to the existing FastAPI backend at
`https://expressonly.in/school/api/`. Used by teaching staff to take and
review class attendance from their phones.

- Min Android: 8.0 (API 26)
- Target Android: 14 (API 34)
- Permissions: `INTERNET` only
- Output APK: ~6 MB

## Build (debug — for development)

Open `android/` in Android Studio (Hedgehog or newer) — it auto-resolves
the wrapper and Gradle plugin. Or from the command line:

```bash
cd android
./gradlew :app:assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk
```

The debug build uses a debug signing key auto-generated by Gradle and is
*not* suitable for distribution.

## Build & sign release APK (for distribution)

**One-time keystore setup** (the keystore is the long-lived release key —
keep it safe, do not commit it):

```bash
cd android
mkdir -p keystore
keytool -genkey -v \
  -keystore keystore/kis-release.jks \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -alias kis
```

Then create `keystore/keystore.properties` (gitignored):

```properties
storeFile=kis-release.jks
storePassword=<your-store-password>
keyAlias=kis
keyPassword=<your-key-password>
```

**Build the release APK:**

```bash
# From repo root:
bash scripts/build-android.sh
```

This runs `./gradlew :app:assembleRelease` and copies the signed APK to
`frontend/public/downloads/kis-attendance.apk`. The next
`/deploy-test-frontend` (or `/deploy-test-all`) publishes it to
`https://expressonly.in/school/downloads/kis-attendance.apk`.

## Verify signature

```bash
$ANDROID_HOME/build-tools/34.0.0/apksigner verify --verbose \
  app/build/outputs/apk/release/app-release.apk
```

Expect `Verified using v1 scheme: true`, `v2 scheme: true`,
`v3 scheme: true`.

## Sideload onto a phone

1. On the phone, enable "Install unknown apps" for Chrome (or whichever
   browser will download the APK). This is a one-time per-source prompt.
2. Open `https://expressonly.in/school/login` in the phone's browser
   and tap "Download for Android".
3. Open the downloaded APK and tap Install.

## Project layout

```
app/src/main/
├── AndroidManifest.xml
├── res/                        Strings, theme, icons, network config
└── java/com/expressonly/kisattendance/
    ├── MainActivity.kt         Single Compose activity
    ├── KisApp.kt               Application (wires up DI container)
    ├── di/AppContainer.kt      Manual DI — no Hilt to keep APK small
    ├── data/
    │   ├── api/                Retrofit ApiService + DTOs
    │   ├── auth/TokenStore.kt  EncryptedSharedPreferences
    │   └── repo/               Auth/Student/Attendance repositories
    └── ui/
        ├── theme/              Material 3 theme
        ├── nav/                NavHost + routes
        ├── components/         StatusChip, ClassDropdown, etc.
        └── screens/            login, home, attendance, history,
                                students, studentdetail
```

## Updating

Bump `versionCode` and `versionName` in
[app/build.gradle.kts](app/build.gradle.kts), rebuild, redeploy. Existing
installs auto-prompt to update next time the user reopens the app's
download link (Android compares signatures — they must come from the
same keystore).
