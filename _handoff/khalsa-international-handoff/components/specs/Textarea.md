# Textarea

> **Kind:** Atom
> Token-only styling. No raw hex / px / font-family literals.


Multi-line text. Same prop surface as `<Input>` (label, hint, error). Default `rows={4}`. Auto-grows up to `maxRows` if provided. Same focus / error / disabled tokens.

Use Punjabi font (`font-gurmukhi`) automatically when `lang === 'pa'` is set on the field or its ancestor.
