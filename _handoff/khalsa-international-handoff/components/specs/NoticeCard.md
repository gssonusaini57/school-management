# NoticeCard

> **Kind:** Molecule
> Token-only styling. No raw hex / px / font-family literals.


Card for a single notice on the website notice board and mobile notices screen.

```
┌──────────────────────────────────────┐
│ [CategoryBadge: Exam]   23 Apr 2026  │
│                                       │
│ Pre-board examinations begin May 6   │
│ Class X and XII students should…     │
│                                       │
│ Read more →                           │
└──────────────────────────────────────┘
```

Props: `category`, `date`, `title` ({en, pa}), `summary` ({en, pa}), `href`, `isUnread` (mobile only — adds Sangat Red dot).
