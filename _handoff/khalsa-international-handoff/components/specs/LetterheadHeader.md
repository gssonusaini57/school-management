# LetterheadHeader

> **Kind:** Print primitive
> Token-only styling. No raw hex / px / font-family literals.


Format A — classic centered seal. The crest is centered, the bilingual school name beneath it, the affiliation line below that.

Top tricolor band (Khalsa Blue 60% / Royal Gold 20% / Sangat Red 20%) at 6px height.

Token usage:
- Crest: 80px wide
- School name: `typography.display` @ 28px
- Lockup: `typography.crestCaps`
- Punjabi name beneath in `fontFamily.gurmukhi`
- Affiliation in `typography.caption`
- Border-bottom: 1.5px `color.border.brand`
