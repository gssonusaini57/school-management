# Illustrations

Use sparingly. Prefer photography for emotional content; reserve illustration for empty states, error states, and abstract section dividers.

Style guide: monoline, 1.5 px stroke, two-tone (Khalsa Blue + Royal Gold accent). Avoid gradients.

Empty states needed:
- Notices empty (`empty-notices.svg`) — open notebook with a feather pen
- Fees empty (`empty-fees.svg`) — receipt with a check mark
- Search empty (`empty-search.svg`) — magnifier
- Offline (`offline.svg`) — disconnected wire

Each SVG: 320 × 240 viewBox, `role="img"`, `<title>` and `<desc>` for screen readers.
