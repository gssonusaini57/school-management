# Favicon & app icons

Generate from `crest-mark.svg` using `pnpm exec real-favicon generate` or RealFaviconGenerator. Required outputs:
- `favicon.ico` (16, 32, 48)
- `apple-touch-icon.png` (180×180)
- `icon-192.png`, `icon-512.png` (PWA manifest)
- `maskable-icon-512.png` (safe area: 80% of canvas)
