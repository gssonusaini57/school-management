# Clean local log backups

## Action

```bash
ls -1d logs_backup_test_* logs_backup_prod_* 2>/dev/null
```

Show the user the list (with sizes via `du -sh logs_backup_*`), then ask for **explicit `y` confirmation** before running:

```bash
rm -rf logs_backup_test_* logs_backup_prod_*
```

## Notes

- Operates only on local disk in the repo root.
- Never touches `/opt/school-management/logs` on the server.
- If no folders exist, just say "Nothing to clean".
