# 06 · Configuration and Environment

> Index: [README.md](README.md) · Previous: [05-execution-and-data-flow.md](05-execution-and-data-flow.md) · Next: [07-design-patterns-and-tradeoffs.md](07-design-patterns-and-tradeoffs.md)

Names and mechanisms only. No real values appear here; where the repository itself
contains a real value, that fact is reported in [08](08-risks-limitations-and-improvements.md).

## 1. Backend runtime settings (`backend/app/config.py`)

Loaded by pydantic-settings from the process environment and from a `.env` file in the
working directory. In production systemd injects `/opt/school-management/.env` via
`EnvironmentFile=`; locally you create `backend/.env`. Template: `deploy/.env.example`.

| Key | Default in code | Read by | Notes |
|---|---|---|---|
| `DATABASE_URL` | local `mysql+pymysql://…/school_management` | `db.py`, `alembic/env.py` | provisioning step 03 creates DB + user and writes the generated password to `/opt/school-management/.db_password`; step 04 writes it into `.env` |
| `JWT_SECRET` | `change-me-in-prod` | `security.py` | generated **on the server** by provisioning step 04 (never on the dev machine); rotating it invalidates every session |
| `JWT_EXPIRY_HOURS` | `1` | `security.create_token` | `deploy/.env.example` also says 1; `.claude/CLAUDE.md` describes tokens as 8 h. **UNKNOWN / needs owner confirmation:** the live value |
| `ADMIN_DEFAULT_PASSWORD`, `SUPER_ADMIN_DEFAULT_PASSWORD` | dev placeholders | `routers/auth.py` seeds | used **only** when the singleton row is missing (first boot); changing them later has no effect — use the in-app change-password or the reset flow |
| `CORS_ORIGINS` | `*` | `main.py` | comma-separated; irrelevant in production because SPA and API are same-origin |
| `LOG_DIR` | `./logs` | `logging_config.py` | prod: `/opt/school-management/logs` |
| `STATIC_DIR`, `BACKUP_DIR` | `../`, `./backups` | **nothing** | dead settings; backups are made by the deploy scripts |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_USE_SSL`, `SMTP_FROM`, `SMTP_FROM_NAME` | Zoho India host, 465, SSL on; user/password empty | `mailer.py` | `email_enabled` requires host + user + password; `SMTP_PASSWORD` is a Zoho *app password*; `SMTP_USE_SSL=false` switches to STARTTLS (then use 587) |
| `APP_BASE_URL` | the TEST portal URL | reset links, notification links, default logo URL | **must** be the portal URL *including* `/admin` (TEST `…/school/admin`, PROD `…/admin`); one comment in `.env.example` omits `/admin` — the code is right |
| `RESET_TOKEN_TTL_MINUTES` | `30` | `routers/auth.py` | — |
| `EMAIL_LOGO_URL` | derived `${APP_BASE_URL}/brand/crest-mark.png` | `email_templates.py` | must be absolute (mail clients cannot load relative images) |
| `APPROVER_NOTIFY_EMAIL` | falls back to the sending mailbox | `notifications.py` | inbox that receives "needs approval" mails |

Two settings bypass `Settings` and are read straight from the environment in
`logging_config.py`: `LOG_LEVEL` (default `INFO`) and `LOG_JSON` (default on; set `0`
for human-readable logs in dev).

## 2. Secrets: where they live and how they get there

| Secret | Created by | Stored at | Never |
|---|---|---|---|
| MySQL `school` user password | `scripts/provision/03-create-mysql-db.sh` (random, on the server) | `/opt/school-management/.db_password` (root, 600) and inside `.env` and `.my.cnf` (school, 600) | committed; typed locally |
| `JWT_SECRET` | `scripts/provision/04-write-env.sh` (generated on the server) | `.env` | shared between TEST and PROD |
| SMTP app password | Zoho console, pasted by the owner | `.env` | in the repo |
| Admin / super-admin passwords | first-boot seed, then changed in-app | bcrypt hashes in `admin_auth` / `super_admin_auth` | in CLAUDE.md (currently are — see 08) |
| Staff passwords | 6-digit initial password generated by `routers/staff.py`, shown once; staff change it | bcrypt in `staff.password_hash` (+ optional `temp_password_hash`) | emailed |
| Android release keystore + its passwords | `keytool` once (see `android/README.md`) | `android/keystore/` (gitignored) and an **offline backup** | in git — but `android/keystore.zip` is tracked; see 08 #1 |
| SSH deploy keys | `ssh-keygen` on the deploy machine | `~/.ssh/…`, path named in `scripts/deploy/*/env.sh` | in the repo |
| MySQL root password (TEST box) | set by the sister project's installer | should exist only in the owner's password manager; passed as `MYSQL_ROOT_PASSWORD` or typed hidden when provisioning | written down in the repo — it currently is (08) |

File permissions on the server are part of the design: `/opt/school-management/` is
`755` (nginx must traverse it), the secret files inside are `600`.

## 3. Frontend build-time configuration (`frontend/`)

The SPA has **no runtime configuration**; everything is baked at `npm run build`.

| Knob | Where set | Default | Effect |
|---|---|---|---|
| `VITE_BASE` | shell env (set by `scripts/deploy/<env>/env.sh`) | `/school/admin/` in `vite.config.ts` | Vite `base`; drives `import.meta.env.BASE_URL` → router `basename`, login redirect, `version.json` URL, favicon placeholder `%BASE_URL%` in `index.html` |
| `VITE_API_URL` | `.env.development` (`/api`), `.env.production` (`/school/api`), overridden by the shell for PROD (`/api`) | — | axios `baseURL`, SSE and inline-file URLs |
| `VITE_BUILD_ID` | optional shell env | ISO timestamp | embedded as `__BUILD_ID__` and written to `dist/version.json` |
| `npm run build` | `package.json` | `tsc -b && vite build` | **always use this**; a bare `vite build` picks up the committed, possibly stale `vite.config.js` |

Browser storage keys (all per-origin): `sessionStorage` `kis_token`, `kis_user`;
`localStorage` `kis_remember` (identifier only), `kis.locale`, `kis.nav.mode`.

Dev server: `npm run dev` → `http://localhost:5173/school/admin/` with `/api` proxied to
`http://localhost:8000` (`vite.config.ts` `server.proxy`). Because the base is
`/school/admin/` even in dev, the root URL `http://localhost:5173/` is a 404 — that is expected.

## 4. Public site build-time configuration (`public-site/`)

| Knob | Where | Default | Effect |
|---|---|---|---|
| `SITE_BASE_PATH` | shell env, read by `src/_data/site.cjs` with `??` | `/school` | prefix for every internal link and asset; PROD passes an **explicit empty string** for the apex root — `??` (not `||`) is what makes that work |
| strings | `_handoff/khalsa-international-handoff/i18n/strings.json` deep-merged with `public-site/i18n/extra-strings.json` | — | build fails loudly only for syntax errors; a missing key renders as `[key]` |
| `npm run build` | `package.json` | Tailwind CLI first (`dist/css/site.css`), then Eleventy | the deploy script checks that `dist/index.html`, `dist/en/index.html` and `dist/pa/index.html` exist |

## 5. Deploy and provisioning knobs (`scripts/`)

`scripts/deploy/test/env.sh` and `scripts/deploy/prod/env.sh` export, with
`SCHOOL_TEST_*` / `SCHOOL_PROD_*` environment overrides:

| Variable | TEST | PROD | Used for |
|---|---|---|---|
| `ENV` | `test` | `prod` | labels and backup filenames |
| `SERVER`, `SSH_USER`, `SSH_KEY`, `DOMAIN` | the shared box, `root`, its key, `expressonly.in` | the dedicated box, `root`, its key, `kisschool.in` | SSH + health URLs |
| `VITE_BASE` / `VITE_API_URL` | `/school/admin/` / `/school/api` | `/admin/` / `/api` | SPA build |
| `SITE_BASE_PATH` | `/school` | `""` | public-site build |
| `HEALTH_PATH` | `/school/api/health` | `/api/health` | post-deploy check |
| `SITE_URL_PATH` | `/school/` | `/` | the URL printed on success |

Prod wrappers also require the operator to type `DEPLOY PROD`; `prod/env.sh` refuses
to run while placeholder values are present. Provisioning (`scripts/provision/provision.sh`)
takes `SERVER`, `SSH_USER`, `SSH_KEY`, `DOMAIN`, prompts for `MYSQL_ROOT_PASSWORD`
(or reads it from the environment), and supports `--inspect-only` and `--force-env`.

## 6. Server layout and process configuration

```
/opt/school-management/            755 school:school
├── app/                           rsync of backend/ (+ .venv/ created on first deploy)
├── frontend/dist/                 rsync of frontend/dist/
├── public-site/dist/              rsync of public-site/dist/
├── logs/                          access.log, error.log, stdout.log, stderr.log (gunicorn/systemd)
│                                  app.log, app.error.log (JSON, rotating 10 MB × 5, from logging_config.py)
├── backups/                       app_<ts>.tgz, db_<ts>.sql.gz, db_manual_<ts>.sql.gz (pruned after 30 days)
├── .env                           600 school
├── .my.cnf                        600 school (mysqldump credentials)
└── .db_password                   600 root
/etc/systemd/system/school-management.service      2 uvicorn workers, --timeout 120, Restart=on-failure
/etc/nginx/snippets/school.conf (TEST)             = deploy/nginx.school.conf, included in the host's SSL block
/etc/nginx/conf.d/kisschool.conf (PROD)            = deploy/nginx.kisschool.conf, own Let's Encrypt cert
```

nginx settings that are load-bearing: `proxy_buffering off` + 24 h read timeout
(SSE), `client_max_body_size 25m` (document uploads), the three exact-match locations
sending `Cache-Control: no-cache, must-revalidate` for the SPA shell and
`version.json`, and the SPA `try_files … /index.html` fallback.

## 7. Mobile app configuration

| Item | Android | iOS |
|---|---|---|
| Version | `android/version.properties` (`versionCode`, `versionName`), auto-bumped by `scripts/build-android.sh` | `ios/version.xcconfig` (`MARKETING_VERSION`, `CURRENT_PROJECT_VERSION`), build number bumped by `ios/scripts/build-ios.sh` |
| API base URL | per flavour via `buildConfigField` in `android/app/build.gradle.kts`: `prod` → kisschool.in, `staging` → expressonly.in/school | hardcoded in `ios/KisAttendance/Data/ApiClient.swift` (production) |
| Application id | `in.kisschool` (prod), `in.kisschool.test` (staging), `.debug` suffix for debug builds | bundle id `in.expressonly.kisattendance` in `ios/project.yml` |
| Signing | `android/keystore/keystore.properties` → `storeFile`, `storePassword`, `keyAlias`, `keyPassword` (gitignored) | Xcode automatic signing; needs an Apple team |
| Update gate | `APP_VERSION_URL` per flavour → `downloads/app-version.json` / `app-version-test.json` with `latest_version_code`, `min_version_code`, `latest_version_name`, `apk_url`, `notes`; written by `scripts/build-android.sh` with `min == latest` | none |
| Network | `res/xml/network_security_config.xml`; `INTERNET` permission only | ATS defaults |
| Release shrinking | R8 + `proguard-rules.pro` keep rules for the DTO package | n/a |

## 8. Per-environment differences at a glance

| | Local dev | TEST | PROD |
|---|---|---|---|
| Portal URL | `http://localhost:5173/school/admin/` | `https://expressonly.in/school/admin/` | `https://kisschool.in/admin/` |
| API reached via | Vite proxy → `:8000` | nginx snippet → `:8000` | nginx vhost → `:8000` |
| `.env` location | `backend/.env` (you create it) | `/opt/school-management/.env` (provisioned) | same |
| `APP_BASE_URL` | whatever you set | TEST portal URL | `https://kisschool.in/admin` |
| MySQL | your own instance | shared instance with `uploadmytds` | dedicated install on a shared box |
| Logs | `backend/logs/` + stdout (`LOG_JSON=0` recommended) | `/opt/school-management/logs/` | same |
| Email | usually unset → forgot-password logs a warning, returns 200 | Zoho mailbox | same mailbox |
| Android build | debug | `staging` flavour, served as `kis-attendance.apk` | `prod` flavour |
| nginx cache-bust headers | n/a | `deploy/nginx.school.conf` | `deploy/nginx.kisschool.conf` |

## 9. Local setup checklist

Backend: Python 3.12, `python -m venv .venv`, `pip install -r requirements.txt`, a
MySQL 8 database, `backend/.env` with at least `DATABASE_URL` (+ `LOG_JSON=0`),
`alembic upgrade head`, `uvicorn app.main:app --reload --port 8000` **from `backend/`**
(pydantic reads `.env` from the working directory). WeasyPrint needs system libraries:
`brew install pango cairo gdk-pixbuf libffi` on macOS, the `libpango… fonts-noto
fonts-lohit-punjabi` packages on Debian/Ubuntu (listed in `backend/app/pdf/render.py`);
without them the PDF routes return 503 and everything else works.

Frontend: Node 20+, `npm ci`, `npm run dev`. Public site: `npm ci`, then
`npm run dev:css` and `npm run dev:html` in two terminals. Android: Android Studio
opens `android/`; `./gradlew :app:assembleStagingDebug` needs no keystore. iOS:
`brew install xcodegen`, `cd ios && xcodegen && open KisAttendance.xcodeproj`.
Git: `git config core.hooksPath .githooks` once per clone.

## 10. Misconfigurations that actually bite (symptom → cause → fix)

| Symptom | Cause | Fix / reference |
|---|---|---|
| Service restarts in a loop right after provisioning or a disk cleanup | `.env` missing or without a valid `DATABASE_URL` | re-run `scripts/provision/04-write-env.sh` (`--force` to rewrite); archive Gotcha 15 |
| Password-reset emails link to the wrong host or to a 404 | `APP_BASE_URL` wrong or missing `/admin` | set it to the portal URL; Gotcha 19 |
| "If an account exists…" but no mail ever arrives | SMTP vars unset → `password_reset_smtp_unconfigured` in `app.error.log` | fill the `SMTP_*` block; `email_enabled` needs host + user + password |
| Users logged out after exactly one hour | `JWT_EXPIRY_HOURS` absent from `.env` → default 1 | set it explicitly; confirm the intended value |
| Users keep seeing the old UI after a deploy | nginx not reloaded with the exact-match `no-cache` locations, or `version.json` not served | reinstall the snippet (`scripts/provision/06-install-nginx-snippet.sh`) or copy the conf + `nginx -t && systemctl reload nginx`; Gotcha 15 |
| SPA assets 404 or the app loads at the wrong path | `VITE_BASE` does not match the nginx `location`, or a bare `vite build` used the stale `vite.config.js` | build with `npm run build` through the deploy scripts; Gotcha 17 |
| Teachers' APK download 404s after a frontend deploy | `rsync --delete` removed `dist/downloads/` because the APK was not rebuilt locally | run `scripts/build-android.sh` first or use `upload-apk.sh`; Gotcha 4 |
| Some browsers do not auto-refresh after another user's change | two gunicorn workers, one in-memory broker each | accept, or `-w 1`, or Redis pub/sub; 08 |
| nginx 500 on every SPA request | `/opt/school-management` not world-traversable | `chmod 755`; archive Gotcha 18 |
| PDF routes return 503 | WeasyPrint system libraries missing | install the packages named in `pdf/render.py` |
| Punjabi text renders as boxes in PDFs | Gurmukhi fonts missing on the server | `fonts-noto` + `fonts-lohit-punjabi` |
| Upload of a scanned certificate fails with 413 | nginx `client_max_body_size 25m` | compress on the client (the web app does; the Android app does not yet) |
| New table missing from `alembic revision --autogenerate` | model not imported in `backend/alembic/env.py` | add the import |
| 500 after a successful write, log shows `KeyError: "Attempt to overwrite 'name' in LogRecord"` | reserved key in `log.*(extra=…)` | rename the key; Gotcha 12 |
| `Data truncated for column 'kind'` | enum column without `values_callable` | copy the pattern in `models/pdf_template.py`; Gotcha 8 |
| Release APK logs in with HTTP 422, debug APK works | R8 renamed DTO fields after a package rename | fix `proguard-rules.pro`; Gotcha 16 |
| Every teacher sees "Update required" the moment an APK ships | `scripts/build-android.sh` writes `min_version_code == latest_version_code` | lower `min_version_code` in the published manifest for optional updates |
| Commit hook never fires on a fresh clone | `core.hooksPath` is local git config | `git config core.hooksPath .githooks` |
