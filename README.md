# KIS School Management Portal
### Khalsa International School, Jalalabad

A complete school management web application built with HTML, Bootstrap 5, and Firebase Firestore.

## 🌐 Live Portal
**[Open Portal →](https://gssonusaini57.github.io/school-management/)**

## Features
- 🔐 Role-based login (Admin & Teachers)
- 👨‍🎓 Student Admissions & Records
- 📋 Daily Attendance with live charts
- 📊 Results / Mark Entry
- 💰 Fee Management & receipts
- 📢 Notice Board (real-time)
- 👩‍🏫 Staff Management & access codes
- 📄 Printable Reports & CSV export
- 🟢 Online / Offline indicator
